**▶ [바로 해보기](https://logan3731.github.io/foresight/archive/foresight/)** — 브라우저에서 바로 실행, 설치·가입 없음, 폰에서도 됩니다.

## 어떤 게임인가

붉은 표식이 이번 턴에 맞을 자리입니다. 적의 수가 전부 공개되므로 **운으로 지는 일이 없습니다.** 지면 잘못 둔 겁니다.

그리고 **죽이는 것만이 답이 아닙니다.**

- 적을 **밀면 예고가 따라 움직여** 공격이 빗나갑니다
- **구덩이로 밀어 넣으면** 체력과 무관하게 사라집니다
- **분열체**는 때려죽이면 둘로 갈라지지만, 구덩이에 빠뜨리면 갈라지지 않습니다
- **거암**은 꿈쩍도 하지 않습니다. 다른 답을 찾아야 합니다

한 턴에 **두 기만** 움직일 수 있습니다. 세 기를 다 쓸 수 있으면 모든 위협을 막을 수 있으니, 매 턴 **무엇을 포기할지** 고르게 됩니다.

12층이고 층마다 목표가 다릅니다 — 소탕 · 버티기 · 돌파 · 보스.

## 만든 방식

**외부 라이브러리 없는 단일 HTML 파일.** 캔버스 2D, 620×1060 세로, 소리까지 코드로 처리합니다. 파일 하나를 브라우저에서 열면 그대로 돌아갑니다.

## 이 저장소를 읽는 법

| 파일 | 내용 |
|---|---|
| [`index.html`](index.html) | 게임 본체. 위 링크가 이 파일입니다 (현재 v10) |
| [`의사결정기록.md`](의사결정기록.md) | 무엇을 왜 정했고, 무엇을 포기했는지 |
| [`개발일지.md`](개발일지.md) | 작업하며 남긴 기록 |

파일은 이게 전부입니다. **지난 버전은 [태그](https://github.com/Logan3731/foresight/tags)로 남아 있습니다** — `v2`부터 `v10`까지, 각 태그에서 그 시점의 `index.html`을 받아 브라우저로 열면 그대로 플레이됩니다. 단일 HTML 파일이라 빌드가 필요 없습니다.

```bash
git show v3:index.html > v3.html   # 특정 버전 꺼내기
```

## 짧은 이력

| 버전 | 바꾼 것 |
|---|---|
| v1 | 규칙과 재미 검증 (도형과 숫자만) |
| v2 | 적 턴을 한 기씩 보여주는 연출 |
| v3 | 전술의 어휘 — 거암 · 분열체 · 끌개 · 균열 |
| v4 | 난이도 — 되돌리기 제한, 증원, 6층 |
| v5 | 권장 턴. 지형으로 처치하면 턴을 돌려받는다 |
| v6 | 「즉사」 표시 — 기회는 있었는데 화면에 없었다 |
| v7 | 시각 언어 정리. 색마다 뜻을 하나씩만 |
| v8 | 12층. 층마다 목표를 바꾼다 |
| v9 | 난이도에 중간이 없던 이유 — 증폭 고리 세 개를 끊었다 |
| v10 | 위협 밀도. 한 턴에 두 기만 |

각 결정의 근거는 [의사결정기록](의사결정기록.md)에 있습니다.
