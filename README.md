# 수신 중

119 상황실의 밤. **전화를 받고, 보낼지 말지 정한다.**

**▶ [바로 해보기](https://logan3731.github.io/foresight/)** — 브라우저에서 바로 실행, 설치·가입 없음. 소리를 켜면 좋습니다.

> 개발 중입니다. 지금 올라가 있는 것은 **밤 1 전체와 밤 2의 도입부**입니다 (30~40분).

---

## 어떤 게임인가

남천시 119종합상황실, 야간조. 오늘부터 혼자 받습니다. 옆자리의 윤 주임은 첫 건만 봐주겠다고 했습니다.

전화는 목소리뿐입니다. 어디인지, 불꽃이 보이는지, 혼자인지 — **질문 하나에 시간이 갑니다.** 두 번째 라인이 깜빡이면 누군가 기다리고 있는 겁니다. 펌프차는 한 대, 구조대 하나, 구급차 하나. 보내면 25분 동안 없습니다.

- 매뉴얼 3번 조항은 **"목소리만 듣고 장난이라 단정하지 말고 우선 출동"**이라고 합니다. 실제 소방청 표준작전절차의 문장입니다
- 그런데 이번 달 여섯 번째 전화한 사람이 있고, 어느 밤에는 아예 **불이 나기 40분 전에 전화가 옵니다**
- 출동시키면 **보낸 사람의 시점**으로 현장에 들어갑니다. 문이 뜨겁고, 시야가 없고, 공기가 줄어듭니다
- 밤이 끝나면 근무 기록이 뜹니다. 틀린 통화는 **다시 들려줍니다** — 어디서 잡을 수 있었는지
- 선택은 다음 밤으로 넘어갑니다. 301호 할머니의 딸이 전화합니다. 윤 주임은 아침에 당신을 보지 않습니다

## 만든 방식

**외부 라이브러리 없는 단일 HTML 파일.** 620×1060 세로, 글자는 한 자씩 찍히고 소리는 전부 코드로 합성합니다(텔레타이프, 벨, 무전 지직, 끊김). 현장 장면도 그림 파일 없이 코드로 그립니다.

통화 절차, 지령 문구, 출동 분류, 과태료, 녹취 보관 기간은 소방청 재난현장 표준작전절차(SOP 500~504)·119종합상황실 표준운영규정·소방기본법을 따랐습니다.

## 이 저장소를 읽는 법

| 파일 | 내용 |
|---|---|
| [`index.html`](index.html) | 게임 본체. 위 링크가 이 파일입니다 (현재 v4) |
| [`journal/`](journal/) | 날짜별 작업 일지 |
| [`archive/`](archive/) | **여기까지 오기 전의 이야기** — 기각된 시제품 넷과 「예지」 전체. [정리](archive/README.md) |

지난 버전은 태그로 남깁니다. `v2`~`v11`은 「예지」, `incoming-v5`부터가 이 게임입니다.

```bash
git show incoming-v5:index.html > incoming-v5.html   # 특정 버전 꺼내기
```
